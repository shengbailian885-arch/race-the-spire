# 尖塔竞速 SpireRace

当前版本 **0.6.4**，适配《杀戮尖塔 2》Windows public-beta **v0.111.0**，支持 **2–4 人**。这是持续联机测试中的模组。

全员在原版房间准备后，由房主点击“启程－竞速”。每人使用相同基础地图、独立路线和单人战斗强度，房间连接负责同步位置、状态、画笔与比赛成绩。终点可选建筑师房间／击败第一幕 Boss／击败第二幕 Boss；全部玩家完成、死亡或退赛后统一结算。

## 安装与使用

1. 所有玩家关闭游戏，解压 `SpireRace-0.6.4.zip`。
2. 将其中的 `SpireRace` 文件夹放入 `D:\steam\steamapps\common\Slay the Spire 2\mods`，覆盖同名模组文件。
3. 确认 `mods\SpireRace` 内直接包含 `SpireRace.dll`、`SpireRace.json` 和本说明，再在游戏模组界面启用。
4. **所有参赛者统一更新至 0.6.4，确认只启用一份 SpireRace。** 本版沿用消息协议 8，但发送端检查点和接收端回放均有修正，请勿与 0.6.3 混用测试。

本模组直接引用原版与 Harmony 接口，没有增加新的前置库要求；已有 BaseLib、RitsuLib 可保留。个人 SL 默认关闭，可设每人 1 次／不限，每次加罚 30 秒；死亡后不能 SL。观战入口在死亡或完成后的等待／结算界面。

当前未实现追赶增益、干扰减益、崩溃重连和房主迁移。观战切入已有战斗时需要短暂后台追赶与校验，不是瞬间恢复任意战斗中间状态；联机延迟取决于网络、战斗长度和模组组合。

### 0.6.4 — 观战黑屏、回合失步与多人重同步修复

- 根据三人测试反馈及本地日志排查：原回放会在玩家队列仍暂停时提前塞入后续回合操作，结束回合时这些操作被原版取消，继而产生“引用的卡牌尚不存在”和检查点失败。黑屏来自未通过校验的同步遮罩；该错误本身不是掉线证据。用户补测中双人可正常观看，不能据此推定三人转发也没有问题。
- 出牌、药水、结束回合等受阶段限制的操作，等待原版进入可出牌阶段后再入队；不再强制解除原版开场的暂停。选牌、恢复与钩子消息继续流转，避免等待选择时卡住。
- 只在原版可出牌阶段、动作队列空闲且未暂停时生成与核对检查点，排除开场准备、抽牌和回合切换的中间状态。
- 修复多人观战相互打断：一名观众申请重同步时，其他观众识别同一战斗的重复初始数据，保留已加载的镜像和播放位置；重叠操作逐项校对，仅追加新增部分，不重复执行。出现不一致则拒绝该包；SL 或真正的新战斗仍清除旧动作并重建。
- 同步时显示建立场景／接收数据／已追赶操作数，避免只显示“正在同步”。缺少初始数据时主动补请求，持续收不到可用数据约 20 秒后返回结算；连续镜像校验失败也只停止该视角，保留比赛。
- 已通过校验的画面不会因短暂动作积压再次切成黑屏，积压时加速追赶。保留首次切入的校验遮罩及失败后的重建保护；不以取消校验来掩盖错误画面。
- 日志增加目标玩家、战斗世代、回合阶段及动作队列信息。错误提示不再直接归因于双方版本不一致。
- 验证：Release 编译 0 警告／0 错误、219 项核心检查；使用 v0.111.0 原版战斗模型录制 44 条操作，两次重建均通过 30 个完整状态检查点，包含三个敌方回合、选牌、临时生成小刀及延迟开场／下一回合测试。另通过三人分包交错、先完成者接收两目标、房主完成后继续转发、两观众重同步互不重置、SL 同时重建及 Godot 遮罩切换检查。测试使用内存存档与独立测试场景，**尚未替代真实三台机器的 Steam 观战复测**。
- 保留以下全部历史更新记录，以及 0.6.3 安装包。

### 0.6.3 — 指定物品获得播报、字幕叠加与多人表情雨

- 获得以下遗物时播报“玩家名 获得了 物品名！”：微型帐篷、化学物X、冰淇淋。“x药”按原版遗物化学物X处理。
- 获得以下卡牌时播报：未掘宝石、添柴、午夜、祭品、肾上腺素、杂技、毒性爆发、大爆炸、武器库、精神过载、电流相生。未掘宝石在本版游戏中属于卡牌。
- 使用 v0.111.0 原版物品 ID 匹配，监听永久牌组加入卡牌及遗物获得事件。奖励预览、抽牌／临时战斗牌、升级、SL 恢复已有物品和观战镜像不触发。之后实际再获得一张指定卡牌，会再次播报。
- Boss 进入和物品获得共用广播区，按收到的顺序从上到下排列，各自显示约 4.5 秒和独立的金色剩余时间条。最多同时显示四条，超出时按顺序排队，每条出队后获得完整展示时间。
- 多条字幕共用下方的表情栏；最后一条字幕结束时一同消失。每次点击给点击时正在显示字幕的所有玩家各发一轮表情雨；发送者也在播报名单中时，自己的屏幕同样播放。
- 同一玩家同时有多条字幕，只计作一名接收者，不会因字幕数量重复播放。没有正在显示的字幕的玩家不播放；该玩家最后一条字幕消失后不再收到新点击，已接收的动画正常播完。
- 房主核验来源并按接收名单转发；点击序号去重。消息协议升级至 8。保留 0.6.2 安装包和以下历史更新记录。
- 验证：编译 0 警告／0 错误、219 项核心检查、14 个原版模型的实际获得事件、升级／预览／SL／观战过滤、多人接收与发送者自身播放、四条字幕独立计时和溢出排队、原版消息序列化及 Godot 界面鼠标交互。截图来自独立测试场景，实际 Steam 多机联机仍需复测。

### 0.6.2 — 广播剩余时间、Boss 表情雨与第二幕终点

- Boss 滚动广播底部新增金色剩余时长条，随本条约 4.5 秒播报逐渐缩短；下一条开始时重新填满。播报与表情按现实时间播放，不随观战追赶加速。
- 新增 🤯、🤢、😅、🥰 四个表情按钮，直接附在 Boss 滚动字幕下方，与本条广播一起出现、一起消失，不再使用独立常驻浮窗。
- 广播仍全员可见；其他玩家在广播期间可以发送表情，只有该条广播中进入 Boss 房的玩家会看到表情雨。发送者与无关玩家不播放，Boss 玩家自己的广播不显示发送按钮。连续广播切换时，按钮自动改为发送给新一条广播的玩家。
- 每次点击产生一轮 6 个大小不同的掉落表情，连续点击分别叠加。只同步表情编号、发送者、接收者与点击序号，接收端自行生成位置、旋转和轨迹。广播消失后不能再发送，已经收到的掉落动画正常播完。
- 房主核验来源与接收者后只向目标玩家转发，接收时去重，避免一次点击重复播放。高密度点击的剩余表情排队处理，限制同时存在的节点数量，不合并正常点击。
- 掉落动画不拦截鼠标，广播文字、时间条与竞速浮窗显示在表情上方。动画不使用战斗随机数，也不修改卡牌、血量、SL 或成绩。
- 准备界面新增“击败第二幕 Boss 后结束”，与第一幕终点互斥；关闭竞速时两项取消，都不勾选则终点为建筑师房间。房主开赛前设置，开赛后锁定并同步全员。
- 第二幕模式下，第一幕 Boss 胜利后继续，击败第二幕 Boss 后该玩家完成；仍等其他玩家全部结束后统一结算。进度窗、规则和结算均显示正确终点。
- 消息协议升级至 7。README 在保留历史记录的基础上追加本版说明；发布包同步更新。
- 验证：编译 0 警告／0 错误、207 项核心检查、原版消息序列化、第二幕规则互斥和配置同步、房主／客户端定向接收与去重、连续点击与排队清理、广播切换接收者、按钮同时消失及真实鼠标点击。提供独立 Godot 渲染截图；真实 Steam 多机效果与第二幕通关仍需联机验收。

### 0.6.1 — 房间切换保护、观战校验与界面调整

- 修复事件房间切换时的越界访问：旧房间仍存在、事件列表已清空时，跳过本帧事件完成检查与文字播报；事件就绪后照常处理。
- 完整记录竞速轮询与观战异常堆栈，方便区分程序异常和连接故障。用户提供的首局报错属于集合下标越界；本机已复现上述同类缺陷，但缺少出错朋友端的原始堆栈，不能确认该局唯一根因。
- 地图只在每名玩家当前节点显示彩色圆环与名字牌；隐藏竞速中原版的历史节点圆圈。同节点玩家使用分层圆环与错开的名牌，离开节点后旧标记移走。
- 标记挂在地图节点上，与地图滚动、缩放同帧移动，去掉原先每 100 毫秒重新定位屏幕坐标造成的拖影。实际位置上报仍受网络频率影响；原版画笔、橡皮及分幕笔迹同步保留。
- 观战先在遮罩后追赶历史动作，匹配接收端当前动作边界的战斗校验值后再显示；检查包含原版可序列化的血量、牌堆、能量、状态及随机状态。
- 后一项玩家操作等待前一项执行阶段结束；选牌与动作恢复消息继续流转。缺少卡牌引用、动作异常、校验失败或长时间无法追赶时请求重同步，连续失败只退出该观战视角，不中止比赛。
- SL 或切换战斗时同时清除旧动作及旧校验记录；消息协议升级至 6。
- 观战重建地图使用与竞速相同的单人布局规则，避免重跑原版地图修改钩子改变录制时的状态。
- 准备窗改为约 61% 不透明度的深色底、淡边框与轻阴影，参考原版角色介绍；文字、勾选框和按钮保持清晰。
- 开赛 3、2、1 改为屏幕正中央的大号金色数字，开赛后自动消失，继续使用原有同步时钟。
- 观战控制栏默认缩至约 720×104 并移至顶部；支持拖动标题栏、右下角缩放、收起／展开，刷新和切换视角时保留手动布局。事件／同步说明窗也支持移动和调整大小。
- 补齐 0.1.0 起的 README 累计更新记录；构建包携带相同 README 和详细测试文档。
- 验证：Release 编译与 97 项核心检查；原版程序集中的旧事件越界复现、修复路径、HP／随机状态校验、动作包／检查点／SL 世代测试；16 个补丁目标；地图同帧跟随及 UI 鼠标交互、倒计时与渲染检查。**尚待真实 Steam 双人战斗中途加入、SL 与连续出牌复测。**
